# 领域说明

公司行动会改变证券数量、现金、成本和可售状态。业务记录通常同时包含公告
版本、除权日、登记日、到账日和更正时间，核算时应区分**事件发生顺序**与
**数据到达顺序**。持仓批次、币种精度、碎股处置和冻结数量属于需要长期保存
的领域信息。

`reference/domain.json` 保存可公开的示例枚举与精度约定。正式业务记录应
使用稳定标识，并区分业务发生时间、系统接收时间和记录版本。

## 核算规则（本服务实现）

### 事件顺序

- 重放只与事件内容有关，与消息到达顺序无关。同日多事件按规则依赖稳定
  排序（`src/ordering.py`）：现金存取 → 拆股 → 确权 → 成交 → 到账交付 →
  红利再投资 → 冻结/解冻 → 跨账户转移 → 持仓核对；同级按业务标识字典序。
- 公司行动按 `action_id` 聚合公告版本，**最高版本生效**；`cancelled`
  整体剔除。每个沿革步骤记录实际采用的版本号。
- 资格规则：除权日重放时点持有、且买入日早于除权日的批次参与确权；
  同日拆股先于确权（按拆股后数量计算）。

### 成本与损益

- 数量精度 6 位小数（`reference/domain.json`），现金 2 位。
- 拆股保持总成本守恒，只调整数量与单位成本；反拆不足一股可现金替代。
- 配股不足一股：向下取整，零碎股按条款现金替代，否则登记残余待处理。
- 现金选择权：按 `cash_option_price` 折现，不产生批次。
- 红利再投资：零头现金保留为明确去向（`reinvest_residual_cash`）。
- 批次成本以证券币种计量，基准币成本在取得日按当日汇率锁定；卖出时
  分解为交易损益与**汇兑损益**（成本外币额 × 汇率变动）。
- 费用按自身币种动账（跨币种费用不强行折算），资本化折算单独记录
  采用的汇率与日期；缺汇率不阻断重放，登记 `awaiting_fx` 待确认。

### 可售与冻结

- 可售 = 数量 − 冻结。冻结/解冻按批次先进先出分摊；冻结份额不可卖出、
  不可转出。配股到账批次可冻结至上市日自动解冻。公司行动权益按全部
  数量计算（含冻结部分），拆股同比例调整冻结量。

### 版本与快照

- 每次重算产生新的核算版本；迟到事件只能产生新版本，已出具的客户快照
  永不覆盖。版本与事件日志哈希绑定。
- 重算校验（持仓核对、数量非负、冻结不超量、成本守恒）任一失败即整体
  放弃，不留半套结果；事件仍在日志中，修正后重算即可。
- 同一日期的持仓核对以最新收到的为准（纠错重发是常态）。
- 汇率取不晚于用汇日的最近一期（最多回溯 7 天），支持反向汇率；
  实际采用的汇率日期与来源写入沿革。
